Bem-vindo à API CRUD com Flask e SQLite

Esta API permite que você execute operações CRUD (Create, Read, Update, Delete) em uma base de dados SQLite.

Listar Usuários Adicionar Usuário

Rotas disponíveis:

  • GET: /users - Retorna todos os usuários no banco de dados.
  • GET: /users/{id} - Retorna um usuário específico por ID.
  • POST: /add_user - Adiciona um novo usuário ao BD.
  • PUT: /edit_user/{id} - Atualiza um usuário existente por ID.
  • DELETE: /delete_user/{id} - Deleta um usuário existente por ID.
