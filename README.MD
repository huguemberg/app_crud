Aplicação CRUD
Esta aplicação demonstra a implementação de operações CRUD (Criar, Ler, Atualizar, Excluir) utilizando o framework Flask e SQLite.

Tecnologias Utilizadas
Python, Flask, SQLite, Pytest

Funcionalidades
A aplicação permite gerenciar informações de usuários

Listar usuarios.
Adicionar usuario.
Editar usuario existente.
Deletar usuario.

Estrutura do Projeto

app_crud: Aplicação CRUD.
templates: Apresentam as interfaces de usuário.
tests: Contêm os paramêtros de testes utilizados pelo pytest afim de testar a aplicação.
